# MA ZIYU Portfolio

最简单的更新方式：

1. 改文字：打开 `content.js`，只修改引号里的文字。
2. 换首页图片：覆盖 `images/bg-clean.jpg` 和 `images/bg-full.jpg`。
3. 换产品图片：把透明 PNG 放进 `images/products/`，文件名与 `content.js` 一致。
4. 本地预览：双击 `index.html`。
5. 发布：在此文件夹运行 `git add . && git commit -m "Update portfolio" && git push`。

没有产品 PNG 时，页面会自动显示彩色占位产品，不会空白。
